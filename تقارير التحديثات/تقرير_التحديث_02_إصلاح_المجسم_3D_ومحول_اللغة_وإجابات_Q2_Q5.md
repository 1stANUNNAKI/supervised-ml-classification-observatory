## 1. 🛠️ إصلاح مشكلة التمدد اللانهائي وسقوط المجسم `[3D MANIFOLD]`

### السبب الجذري للمشكلة (Root Cause)
كانت دالة حلقة الرسم `startRenderLoop()` تقرأ `this.canvas.clientHeight` في كل إطار (`requestAnimationFrame`) ثم تضبط `this.canvas.height = h * dpr` (حيث `dpr = window.devicePixelRatio` مثل `1.25` أو `2.0`). وبسبب عدم وجود `position: absolute` على عنصر `#manifold3dCanvas` داخل حاوية Flex، كان المتصفح يوسّع ارتفاع العنصر الأب في كل إطار بمقدار مضاعف الـ `dpr`، مما يؤدي إلى تضخم النافذة السوداء للأسفل باستمرار وهبوط مركز المجسم (`height * 0.52`) إلى الأسفل بلا توقف.

### الحل الهندسي المنفذ
1. **قفل أبعاد الحاوية في `assets/css/observatory.css`:**
   - ضبط `.manifold-canvas-wrap` على ارتفاع صارم ثابت (`height: 390px; min-height: 390px; max-height: 390px; flex: 0 0 390px; position: relative; overflow: hidden;`).
   - فصل `#manifold3dCanvas` عن تدفق الـ Flex عبر `position: absolute; top: 0; left: 0; width: 100% !important; height: 100% !important;`.
2. **منع إعادة التحجيم المتكرر في `assets/js/manifold-3d.js`:**
   - تخزين الأبعاد السابقة (`this._lastW`, `this._lastH`, `this._lastDpr`) بحيث لا يتم تعديل `canvas.width` أو `canvas.height` إلا عند تغير حجم النافذة الفعلي أو تفعيل وضع ملء الشاشة، مع استخدام `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` لضمان ثبات الإحداثيات بنسبة 100%.
