# 05 — مصفوفة مقارنة النماذج ومعايير الاختيار (Model Comparison Matrix)

## فلسفة المفاضلة الموجهة لرئيس البيانات (CDO Justification)
في سياق الاحتفاظ بالعملاء المؤسسيين، **تكلفة السلبية الكاذبة (False Negative — عدم اكتشاف عميل سيتسرب، وتكلفته متوسط خسارة عقد بقيمة $4,200)** تفوق بكثير **تكلفة الإيجابية الكاذبة (False Positive — تقديم عرض استبقاء أو اتصال استباقي بعميل مستقر، وتكلفته $180)**.
لذلك، لا نكتفي بـ `Accuracy` وحدها بسبب عدم توازن الفئات (73.6% مقابل 26.4%)، بل نعتمد:
1. **`ROC-AUC` و `PR-AUC`** لقياس القدرة التمييزية عبر كافة العتبات.
2. **`Recall (Sensitivity)` و `F1-Score`** لضمان التقاط أكبر نسبة من العملاء المعرضين للتسرب.
3. **القابلية للتفسير (`Interpretability`)** عبر أهمية المتغيرات ومساهمات كل متغير لتوجيه فرق نجاح العملاء (Customer Success).
4. **النموذج الفائز الموصى به:** **Gradient Boosting Classifier** (مدعوماً بـ **Logistic Regression** كمرجع خطي شفاف لمعاملات الأرجحية `Odds Ratios`).
